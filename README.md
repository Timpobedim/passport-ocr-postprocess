# passport-ocr-postprocess — принять паспорт или попросить переснять

Модель распознала паспорта РФ. По каждому документу нужно решить: принять и выдать 10 полей или отклонить. Принятый документ с ошибкой обходится намного дороже отказа.

Решение не доверяет уверенности модели — у неверных символов она бывает 0,999. Каждое поле подтверждается независимо:

- ФИО, пол, даты, серия и номер, код подразделения — совпадают с машиночитаемой зоной (MRZ), у строки 2 которой сошлись все контрольные цифры;
- место рождения и «кем выдан» — строки покрывают рамку поля (нет потерянной строки) и риск ошибки по словам ниже порога;
- паспорт действителен на 01.10.2026.

Результат на test: **принято 507 из 2000, прогноз ошибок — около 6**. Как получен прогноз и что выяснилось о данных — в [REPORT.md](REPORT.md).

## Запуск

Нужен Python 3.12 и numpy; работает на CPU без сети.

```bash
pip install -r requirements.txt
python postprocess.py data/test_predictions.jsonl answers.jsonl
```

Файлы `train_predictions.jsonl` и `train_labels.jsonl` должны лежать рядом с входным файлом (или в `data/`): по ним при запуске за пару секунд обучается модель риска. Справочник подразделений — в `reference/` (DaData, CC BY-SA 4.0, см. `reference/SOURCE.txt`).

Готовые ответы для test — [`answers.jsonl`](answers.jsonl).

## Проверка

```bash
python experiment.py           # кросс-валидация на train: сколько принято и сколько с ошибкой при разных порогах
python experiment.py --errors  # ошибки принятых документов и причины отказов
pytest                         # 18 тестов: контрольные цифры, транслитерация, век в датах, срок действия, потерянная строка, CLI
```

## Устройство

| Файл | Что делает |
|---|---|
| `mrz.py` | разбор MRZ паспорта РФ, контрольные цифры, транслитерация, починка строки с лишним или пропущенным символом |
| `fields.py` | поля из визуальной зоны и их сверка с MRZ |
| `risk.py` | риск ошибки в месте рождения и «кем выдан»: частоты слов и пар, словарь с поиском слов на одну правку, уверенность |
| `postprocess.py` | исправление века в датах, срок действия, решение и запись ответов |
| `experiment.py` | честная оценка на train пятикратной кросс-валидацией |
